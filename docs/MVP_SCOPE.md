# CodexBar 0.1.3 — MVP 范围

## 产品目标

用一次全局快捷键打开 Spotlight 风格浮层，在明确的工作目录中快速启动 Codex，省去“打开终端 → cd → 输入 codex → 再输入任务”的重复操作。

## P0：本版本已实现

1. **全局快捷键**：默认 `⌥ Space`，提供 4 个预设组合。
2. **Spotlight 风格浮层**：无 Dock 图标、始终浮于前台、Esc 或点击外部关闭。
3. **临时固定窗口**：图钉开启后失去焦点不收起；应用重启恢复默认弹窗模式。
4. **工作目录管理**：左侧添加、切换、移除、Finder 定位；自动持久化。
5. **并行后台执行**：每个 `codex exec` 使用独立进程和输出管道，可连续提交多个任务。
6. **任务中心**：切换查看各任务状态和结构化 Agent 时间线，可单独停止、移除或批量清理已完成任务。
7. **终端交互**：通过 Terminal 启动 Codex TUI，可带初始任务，也可留空直接进入。
8. **Codex 自动检测**：通过用户登录 Shell 查找 `codex`；也可手动指定可执行文件。
9. **历史记录**：独立入口保留最近 100 条，可恢复任务、目录和执行模式，也可单条删除或清空。
10. **安全默认值**：每次启动默认后台模式；后台使用 `workspace-write`，不启用危险的全权限绕过参数。
11. **菜单栏入口**：左键打开；右键可打开历史、任务中心、切换固定状态或退出。
12. **标准编辑快捷键**：输入框支持 macOS 常用复制、粘贴、全选、撤销与重做。
13. **结构化输出**：使用 `codex exec --json`，分别渲染 Codex 回复、思考、命令、文件变更、执行计划、MCP、网络搜索和错误。
14. **输出跟随**：打开任务时默认定位到底部；有新事件时自动跟随，向上查看旧内容时显示“回到底部”入口。
15. **Markdown 展示**：回复支持标题、列表、强调和代码块；代码块可一键复制。

## 会话与持久化边界

- 工作目录、快捷键、Codex 路径和历史记录持久化。
- 后台任务完整输出只保留在当前应用会话，不持久化。
- 当前会话最多保留 30 个任务卡片；超出时只清理最旧的已完成任务，不中断运行中的任务。
- 固定窗口属于临时状态，不写入偏好设置。

## P1：建议下一版

- 后台任务完成通知和失败提醒。
- 任务输出写入本地日志，可在重启后继续查看。
- 自定义快捷键录制器，而不是固定预设。
- 登录时启动（SMAppService）。
- 任务模板：修 Bug、代码审查、生成测试、执行项目内固定脚本。
- 每个工作目录保存默认模式、默认模型、默认 prompt 前缀。
- `codex resume --last` 快速续接上次会话。
- iTerm2 / Warp / Ghostty 终端适配。

## 暂不做

- 在 SwiftUI 内完整嵌入 Codex TUI。终端 TUI 依赖伪终端、ANSI 渲染、窗口尺寸同步和交互审批，MVP 直接复用成熟终端更稳。
- 默认使用 `--dangerously-bypass-approvals-and-sandbox`。
- Mac App Store 分发。当前工具需要运行本地 CLI 并控制 Terminal，优先按 Developer ID 直装应用设计。

## 版本记录

### 0.1.3

- 后台执行切换到 Codex 官方 JSONL 事件流。
- 输出改为 Agent 时间线，区分回复、思考、命令、文件变更、计划、MCP、搜索和错误。
- Codex 回复支持 Markdown 与独立代码块展示，代码块可复制。
- 任务输出首次打开和持续更新时默认滚动到最底部；上滚后提供“回到底部”按钮。
- 未识别的新 Codex 事件保留为诊断卡片，避免信息静默丢失。

### 0.1.2

- 新增独立历史记录入口。
- 后台模式支持多个任务并行执行和切换查看。
- 新增任务中心及单任务停止、移除、清理已完成任务。
- 新增临时固定窗口模式，默认仍为失焦自动收起的弹窗模式。

### 0.1.1

- 将 `--ask-for-approval never` 放到 `exec` 子命令之前，兼容不接受子命令后全局参数的 Codex CLI 版本。
- 输入框补齐 macOS 标准编辑快捷键。
- 应用每次启动默认选择后台执行模式。
